# 工程假设与判据

- 常物性液态水，绝热壁面，无重力、相变、辐射或固体传热。默认数字只是演示，不是可信手册引用；source字段应由项目人员填写准确来源，measured只表示声明而非系统认证。
- 前置雷诺数阈值2300/4000仅用于提示，弯头及混合流动需要工程判断。
- 网格：最小体积>0，最大歪斜度<0.95，最小正交质量>=0.1；长宽比>100提示近壁解释。日志无法可靠提取指标时阻止求解，不承诺自动适配所有版本格式。
- 瞬态Co=入口最大速度×时间步/名义网格尺寸；不包含局部最小网格或实际局部速度，不能证明稳定性或时间精度。
- 残差：能量<=1e-6，连续性、速度和湍流<=1e-4。稳态出口温度最近10个采样点变化<=0.1 K，采样间隔10次迭代；短运行证据不足。
- 质量不平衡<=1%，相对于总入口绝对质量流量。焓流不平衡<=2%，使用常cp及273.15 K参考；不是任意材料的完整能量审计。默认绝热且不含粘性耗散。
- 温度不应超出入口温度范围0.5 K；出口理想混合温度差>1 K提示。回流及未充分混合应结合质量加权采样解释。
- 瞬态每步收敛和观察窗口充分性需要本地历史证据；缺失时不标通过。压力/速度使用可配置宽范围筛查，不能替代项目工况约束。绝对压力使用101325 Pa操作压力换算，液态假设采用IAPWS 1992饱和压力方程预筛查，不构成汽蚀分析。
- 没有网格独立性、近壁y+复核、时间步敏感性和实验对照，不能用于产品验收。

判据可通过工况的validation字段或--rules YAML覆盖；配置与输入一并保存。

## 单位契约

用户与Schema全部SI；CAD构建显式换算为mm，STEP声明mm，Meshing以mm导入且尺寸控制换算为mm。Solver读取网格后查询三个端口节点位置/直径：若已为m则不缩放，若证据明确为mm则缩放0.001并再次核验，否则阻断。STEP回读测试同时检查毫米体积到m³的换算，避免仅比较无单位数字。
