# 架构

GLM -> 需求校验 -> CadQuery/OpenCASCADE -> 几何校验 -> Fluent Meshing -> 网格校验 -> 物理/物性/时间步校验 -> PyFluent算例构建 -> 回读校验 -> 求解与过程监控 -> 后置校验 -> 报告。

几何模板固定，两个入口和一个出口。几何坐标：主管由-X向+X进入，弯头转向+Y；支管由下方向+Y进入，Z为横向。支管接入中心线参数默认60°，不是从图片测得的真实尺寸。用户需根据实际工程尺寸调整。

模块：schemas为统一数据对象；llm仅解析；geometry创建真实流体域；fluent封装本地2024 R2接口；validation定义确定性规则；orchestrator负责顺序状态机和门禁；reporting汇总证据。

GLM不决定规则结果或直接运行命令。材料、日志和参数无密钥。失败保留运行目录，禁止自动将缺失数据填成通过。

本地进程在退出时关闭；文件为可保留产物。云环境不连接用户本地计算机，用户需在本地安装Harness并执行。
